# 🍎 Fruity Forest

**Fruity Forest** is a 2D casual game built with **Unity**, where fruits fall from the sky and the player controls a basket to catch them. Each caught fruit increases the score, while missed fruits reduce the player’s lives.

This project was developed as a complete Unity game, covering gameplay logic, UI, input handling, and scene management.

---

## 🎮 Gameplay Overview

- Fruits spawn randomly at the top of the screen
- The player moves a basket horizontally to catch fruits
- Catching fruits increases the score
- Missing fruits decreases life
- The game ends when all lives are lost

---

## ✨ Features

- 🎯 Score and life system
- 🧺 Basket movement using keyboard input
- 🍓 Multiple fruit prefabs
- 🔄 Continuous spawning system
- 🖥️ UI built with **Unity UI Toolkit (UXML + USS)**
- 🎬 Scene-based flow (Main Menu → Gameplay → Game Over)
- 🧠 Clean, modular C# scripts

---

## 🛠️ Tech Stack

- **Engine:** Unity 6 (URP)
- **Language:** C#
- **UI:** Unity UI Toolkit (UXML, USS)
- **IDE:** JetBrains Rider
- **Version Control:** Git & GitHub
- **Platform:** Desktop (Windows / macOS)
